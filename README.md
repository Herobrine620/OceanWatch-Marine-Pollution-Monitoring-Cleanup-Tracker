## 🎯 Project Objective

Marine pollution is a major environmental challenge. Identifying polluted areas, recording the type and amount of waste, and ensuring that reported locations are cleaned can be difficult without organized data.

OceanWatch provides a simple digital workflow:

**Detect → Understand → Act → Measure → Share**

The platform allows pollution observations to be recorded and connected with locations and cleanup activities.

## ✨ Features

- 📷 Upload pollution photographs

## 🤖 AI-Based Waste Detection

The current project contains a **front-end prototype** of an AI-based waste detection system.

The interface demonstrates how an uploaded pollution image could be processed to identify and classify waste.

A future implementation can connect the system to a trained computer-vision model or an AI detection API.

```text
        UPLOADED PHOTO
               ↓
       AI / VISION MODEL
               ↓
       WASTE DETECTION
               ↓
      WASTE CLASSIFICATION
               ↓
        OBJECT COUNTING
               ↓
     POLLUTION ESTIMATION
               ↓
       LOCATION + DATA
               ↓
      CLEANUP NOTIFICATION
```

A model trained specifically on marine pollution images could improve detection of:

* Plastic bottles
* Plastic bags
* Plastic packaging
* Food containers
* Fishing waste
* Other plastic debris

---

## ⚠️ Limitations

The current version is a prototype and has several limitations:

* It does not currently contain a custom-trained computer-vision model.
* Waste detection is demonstrated through the prototype interface.
* Detection accuracy would depend on image quality, lighting, camera angle, and visibility of waste.
* Different types of marine debris may not always be correctly classified.
* Waste quantity and pollution severity are currently estimates rather than scientifically measured values.
* Location detection depends on browser permissions and available location services.
* The current version does not use a large-scale cloud database.

Integrating a trained AI model or suitable detection API would improve the accuracy and reliability of plastic-waste detection.
